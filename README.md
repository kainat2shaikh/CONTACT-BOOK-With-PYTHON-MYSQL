# CONTACT-BOOK-With-PYTHON-MYSQL
A Command Line Contact Management System With **Python**, **MySQL** and **PrettyTable**.

## Features:
- Adding A Contact
- Viewing Your Cantact Book
- Searching For A Contact
- Updating A Contact (Name|Mobile Number|Email|City)
- Delete A Specific Contact (With Yes/No)
- Delete All Contacts (With Confirmation)

## Tech Stack
- **Language:** Python 3
- **Database:** MySQL
- **Libraries:** `mysql-connector-python`, `PrettyTable`, `re`

## How to Run This Project
1. Download or clone this repository to your computer.
2. Install the required Python libraries by running `pip install -r requirements.txt`.
3. Open `schema.sql` in MySQL and run the queries to create the database and table.
4. Open `ContactBook.py`, enter your local MySQL password, and run `python3 main.py`.
